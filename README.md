# Peluquería López García

Landing page de Peluquería López García, salón de peluquería de barrio en Las Delicias (Valladolid), abierto desde el 11 de mayo de 2013.

**Web en producción:** https://peluquerialopezgarcia.lovable.app

## Sobre el proyecto

Sitio web de una sola página (landing) pensado para dar presencia digital propia a un negocio de barrio que hasta ahora solo existía en redes sociales y plataformas de terceros (Facebook, Instagram, Fresha). El diseño mantiene una estética cálida y cercana —coherente con la identidad de "peluquería de familia, para tu familia"— evitando una imagen fría o de cadena.

### Secciones de la web

- **Inicio** — hero con imagen del local, titular y llamada a la acción para pedir cita
- **Sobre nosotros** — historia del salón desde 2013 y su relación con el barrio
- **Servicios** — corte y peinado, color y mechas, tratamientos capilares, alisados y ondas, recogidos y eventos, peluquería infantil
- **Nuestro trabajo** — carrusel de fotos del local y enlace al feed de Instagram
- **Reseñas de Google** — valoraciones de clientas
- **Horario y ubicación** — tabla de horarios y mapa de Google Maps embebido
- **Contacto** — teléfono, WhatsApp con mensaje precargado, redes sociales

## Tecnologías

- [Vite](https://vitejs.dev/) + TypeScript
- [shadcn/ui](https://ui.shadcn.com/) (ver `components.json`)
- [Bun](https://bun.sh/) como gestor de paquetes
- ESLint + Prettier
- Construido y sincronizado con [Lovable](https://lovable.dev)

## Desarrollo local

Requisitos: [Bun](https://bun.sh/) instalado.

```bash
git clone https://github.com/10198aprieto/peluquerialopezgarcia.git
cd peluquerialopezgarcia
bun install
bun run dev
```
